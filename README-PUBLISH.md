# Divyasree Woven Sacks — Publishing Guide

This is a complete static website. It does not require a database or paid software.

## Before publishing

1. Open `index.html` and confirm the company wording and contact details.
2. The supplied phone/WhatsApp numbers are already inserted.
3. The WhatsApp enquiry button currently uses +91 92466 28685.
4. If the final domain is different from `https://divyasreewovensacks.com/`, replace that domain in:
   - `index.html` canonical URL and social URL
   - `robots.txt`
   - `sitemap.xml`

## Free/low-cost hosting

You can publish this folder using a static hosting service. Upload all files in the same folder.

For a custom `.com` domain:
- Register `divyasreewovensacks.com` with a domain registrar if available.
- Connect its DNS records to your hosting provider.
- Enable HTTPS/SSL.

## Google indexing

After the site is live:
1. Open Google Search Console.
2. Add the domain/property.
3. Verify ownership.
4. Submit `https://divyasreewovensacks.com/sitemap.xml`.
5. Use URL Inspection to request indexing of the home page.

Google indexing is free, but indexing does not guarantee a particular search ranking.
